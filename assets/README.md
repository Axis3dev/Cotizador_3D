# Assets

Coloca aquí el archivo del logo del negocio (por ejemplo, `logo_negocio.png`).

El programa buscará la ruta configurada en `config.json` (clave `identidad.logo_path`).
Si el archivo no existe, las exportaciones a PDF y Excel simplemente omitirán el logo,
de modo que puedes agregarlo posteriormente sin necesidad de versionarlo en Git.
